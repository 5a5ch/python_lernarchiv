# Python-Lernarchiv

Dieses Repository dokumentiert meinen Lernweg beim Erlernen von Python aus dem Unterricht.

Der Schwerpunkt dieses Archivs liegt nicht auf perfekten oder hochoptimierten Lösungen, sondern auf dem nachvollziehbaren Lernprozess. Viele Aufgaben enthalten mehrere Versionen (v1, v2, v3), damit die Entwicklung eines Lösungsansatzes sichtbar bleibt.

## Ziel

Ziel dieses Repositories ist es,

- grundlegende Programmierkonzepte zu erlernen,
- eigene Lösungswege zu dokumentieren,
- Lernfortschritte festzuhalten,
- verschiedene Lösungsansätze miteinander zu vergleichen,
- und eine persönliche Sammlung von Python-Übungen aufzubauen.

## Aufbau

### Grundlagen

Ein- und Ausgaben, Bedingungen, Zufallszahlen und erste kleine Programme.

Beispiele:

- Hundealter
- Portokosten
- Begrüßung
- Zahl raten

### Schleifen

Übungen mit `for`- und `while`-Schleifen.

Beispiele:

- Zahlenreihen
- Potenzen von 2
- Sternenmuster
- Dominosteine
- Ulam-Folge

### Funktionen

Eigene Funktionen mit Parametern und Rückgabewerten.

Beispiele:

- Teilersumme
- Nettopreis
- Kostenberechnung
- Passwortqualität

### Algorithmen

Etwas umfangreichere Aufgaben und Lösungsstrategien.

Beispiele:

- Bubble Sort
- Fakultät
- ggT
- Bananenproblem
- Datumsprüfung

### Objektorientierte Programmierung (OOP)

Übungen zu Klassen, Vererbung, Assoziation und Methoden.

Beispiele:

- Auto
- Konto
- Rechteck
- Mitarbeiter und Manager
- Fahrzeug und LKW

### GUI

Erste grafische Benutzeroberflächen mit tkinter.

Beispiele:

- Klick-Zähler
